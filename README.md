# Filmoteca

**Filmoteca** — это приложение для хранения и воспроизведения фильмов в формате `mp4`. Проект предоставляет удобный интерфейс для загрузки, управления и просмотра фильмов.

**Технологии**:
Java 17+
Spring Boot
Lombok
Gradle

**Планируемые улучшения**
Добавление базы данных (MySQL)
Воспроизведение фильма формата mp4
