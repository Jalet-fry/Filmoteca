# Filmoteca

**Filmoteca** — это современное приложение для хранения и управления фильмами в формате `mp4`. Проект предоставляет удобный интерфейс для загрузки, организации и воспроизведения видеофайлов, делая процесс управления медиатекой простым и эффективным.

---

## 🚀 **Основные возможности**
- ✅ Загрузка и хранение фильмов в формате `mp4`
- 🎬 Удобное управление библиотекой фильмов
- 📂 Воспроизведение видеофайлов напрямую через приложение
- 🌐 RESTful API для интеграции с другими системами

---

## 🛠️ **Используемые технологии**
- ☕ **Java 17+**
- 🌱 **Spring Boot**
- ⚡ **Lombok**
- 📦 **Gradle**

---

## 📅 **Планируемые улучшения**
- 🗄️ Интеграция с базой данных (MySQL) для хранения метаданных фильмов
- 🎥 Оптимизация воспроизведения видеофайлов формата `mp4`
- 📊 Расширение функционала для управления коллекциями фильмов

---

**Filmoteca** — это идеальное решение для любителей кино, которые хотят организовать свою медиатеку и наслаждаться просмотром фильмов в удобном формате.
