# Filmoteca

**Filmoteca** — это простое RESTful веб-приложение для управления фильмами. Оно позволяет создавать, получать и искать фильмы по различным параметрам. Проект реализован с использованием Spring Boot и предоставляет базовые CRUD-операции для работы с фильмами.

---

## Основные функции

- 🎬 **Добавление фильма**: Создание нового фильма с указанием названия, года выпуска и пути к файлу.
- 🔍 **Поиск фильма по названию**: Получение информации о фильме по его названию.
- 📂 **Получение фильма по ID**: Получение информации о фильме по его уникальному идентификатору.
- 📋 **Получение всех фильмов**: Получение списка всех доступных фильмов.

---

## Технологии

- **Java 17**
- **Spring Boot**
- **Spring Web**
- **Lombok** (для сокращения boilerplate-кода)
- **Gradle** (для управления зависимостями)
